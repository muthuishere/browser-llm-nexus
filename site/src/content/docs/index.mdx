## Private LLM in any browser. GPU optional.

Most "LLM in the browser" projects are a WebGPU demo. A demo excludes the locked-down
corporate laptop with no GPU adapter — which is exactly the machine where *"the data
must not leave this page"* actually matters.

Here, **GPU is an accelerator, never a requirement.** Every loader picks WebGPU when the
browser exposes a usable adapter and falls back to WASM/CPU otherwise, and your code does
not change either way.

```bash
npm install browser-llm-nexus
```

```ts
import { NexusChat } from 'browser-llm-nexus';

const chat = await NexusChat.load({ hub: 'onnx-community/Qwen3-0.6B-ONNX' });

chat.tool('get_weather', 'Get current weather for a city',
  { city: 'string' },
  async ({ city }) => (await fetch(`/api/weather?c=${city}`)).json());

chat.on('token', t => render(t));
console.log(await chat.chat('What is the weather in Chennai?'));
```

## Standalone by design

No server of ours. No bundled weights. No assumed layout. Transformers.js is an
*injectable* peer dependency, and **where a model comes from is always something you
state** — never guessed.

```ts
await NexusChat.load({ hub: 'onnx-community/Qwen3-0.6B-ONNX' });  // Hugging Face
await NexusChat.load({ base: '/models/', id: 'Qwen/Qwen3-0.6B' }); // your own host
await NexusChat.load({ archive: fileTheUserPicked });              // a portable zip
```

## The sister library

**[toolnexus](https://github.com/muthuishere/toolnexus) gives any LLM tools.
browser-llm-nexus gives you the LLM.** One runs on your server in six languages, one runs
in the tab with no server at all — and both emit the same OpenAI function schema.
[See how they fit together](/browser-llm-nexus/toolnexus/).
